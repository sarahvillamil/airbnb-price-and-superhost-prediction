## Classification Prediction Problem
### Sub-directories

### R Scripts
-   '01_initial_cleaning.r': EDA of data.
-   '02_initial_setup.r': Folding.
-   '03_Recipes.r': Recipes for models.
-   '04a_Null_fit.r': Null model.
-   '04b_logis_reg_fit.r': Logistic Regression model.
-   '04c_bt_fit.r': Boosted Tree model.
-   '04d_rf_fit.r': Random Forest model.
-   '04e_knn_fit.r': Nearest Neighbor Model.
-   '04f_light_bt_fit.r': Light Boosted Tree model.
-   '04g_mars_fit.r': Multivariate Adaptive Regression Splines model.
-   '04h_nnet_fit.r': Neural Net model.
-   '04i_svm_poly.r': Support Vector Machine Polynomial model.
-   '04j_svm_radial.r': Support Vector Machine Radial model.
-   '05_model_analysis.r': Model comparison and analysis.
